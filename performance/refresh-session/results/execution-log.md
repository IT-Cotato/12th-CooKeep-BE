# 측정 실행 로그

시각은 UTC다. 공식 RPS 분모는 k6 command wall time이 아니라 고정된 본 측정 180초다.

command wall에는 k6 컨테이너 시작과 종료 유예가 포함된다. 공식 RPS는 결과의 `refresh_completed / 180`으로 계산했다.

실행별 자세한 시각, 이미지, 커밋, 사용자 범위, 요청 수와 유효성 판정은 각 `a-runN.json`, `b-runN.json`에 기록돼 있다. 이 문서는 공개용 실행 순서와 판정 요약만 제공한다.
